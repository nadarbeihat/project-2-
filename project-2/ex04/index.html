The Box Model

Both boxes have the same CSS: width 300px, padding 20px, border 10px.

Reference: 300px

box-sizing: content-box

Content width = 300px.
Total width = 300 + 20 + 20 + 10 + 10 = 360px.

box-sizing: border-box

Total width = 300px.
Padding and border are absorbed inside it.
Content width = 300 - 20 - 20 - 10 - 10 = 240px.

Inspect each box in DevTools to see the box model diagram.
